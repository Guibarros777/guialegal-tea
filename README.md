## 🚀 Sobre o Projeto
O **GuiaLegal TEA** é uma aplicação web progressiva (PWA) desenvolvida para auxiliar famílias atípicas, pessoas autistas e profissionais na defesa de direitos, organização de dossiês jurídicos, simulações previdenciárias e comunicação rápida em situações de crise ou deslocação urbana.

## ✨ Principais Funcionalidades

- **🪪 Passaporte Sensorial Digital:** Credencial oficial baseada na Lei Romeo Mion e Lei CIPTEA para identificação rápida de necessidades sensoriais, gatilhos, formas de comunicação e contactos de emergência de anjos guardiões.
- **🚨 SOS Crise (Modo de Emergência):** Ferramenta rápida para suporte imediato e de desescalada em momentos de sobrecarga ou crise sensorial.
- **💰 Calculadora BPC/LOAS:** Estimativas e orientações detalhadas sobre critérios de elegibilidade para benefícios assistenciais.
- **⚖️ Simulador de Perícia & Dossiês:** Ferramentas para preparação de documentação, auditoria de planos de saúde e gestão de prazos jurídicos.
- **🗺️ Guia Inclusivo & Estabelecimentos:** Mapeamento de locais preparados e inclusivos.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando uma arquitetura moderna Full-Stack:

* **Front-end:** React, TypeScript, Tailwind CSS, Vite, Lucide React, Motion (Framer Motion).
* **Back-end:** Node.js, Express, TypeScript (`tsx`).
* **PWA (Progressive Web App):** Suporte offline e instalação direta em dispositivos móveis.
* **Deploy & Hospedagem:** Render & GitHub.
